# Казахский дактиль

## Публикация сайта на GitHub Pages и API на Render

GitHub Pages размещает статические файлы. Python-распознавание работает отдельно на Render; браузер отправляет ему кадры камеры по HTTPS.

1. Отправьте файлы проекта в репозиторий GitHub.
2. На Render создайте **New → Blueprint**, выберите репозиторий и примените настройки из `render.yaml`. API собирается из `Dockerfile`, где вместе с Python устанавливаются системные библиотеки MediaPipe, включая `libgles2`. После публикации скопируйте адрес сервиса, например `https://kazakh-sign-api.onrender.com`.
3. В `config.js` укажите полученный адрес:

   ```js
   window.APP_CONFIG = {
     API_BASE_URL: "https://kazakh-sign-api.onrender.com"
   };
   ```

4. В GitHub откройте **Settings → Pages**, выберите публикацию из ветки `main` и корня репозитория, затем сохраните настройки. Сайт будет доступен по адресу `https://baakha.github.io/sign-language-project/`.
5. Откройте сайт, разрешите доступ к камере и выполните калибровку шаблонов.

`CORS_ORIGINS` в `render.yaml` разрешает запросы с `https://baakha.github.io` и `https://langict.pryopj`. Если Pages опубликован на другом домене, добавьте его origin в настройку Render `CORS_ORIGINS` (только схема и домен, без пути и завершающего `/`), затем примените изменение и дождитесь перезапуска сервиса. Открывайте страницу по HTTPS: браузер разрешает веб-доступ к камере только на защищённом сайте или `localhost`.

### Хранение данных и ограничения

- Камера работает в браузере, но кадры передаются на Python-сервер для распознавания.
- Образцы калибровки хранятся на сервере отдельно для каждого браузера. Для сохранения образцов после перезапуска подключите на Render постоянный диск, смонтированный в `/var/data`, и задайте `LOCALAPPDATA=/var/data`.
- Бесплатный экземпляр Render может засыпать; первый запрос после простоя будет медленнее. Без постоянного диска данные калибровки могут пропасть после перезапуска.
- Сервер обслуживает до 4 активных браузерных сессий; неиспользуемые сессии удаляются через 30 минут.

## Локальный запуск

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
.\.venv\Scripts\python.exe .\run_web.py
```

Откройте `http://127.0.0.1:8000` и разрешите браузеру доступ к камере.
